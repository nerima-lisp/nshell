# 字句と読み取り

## 1.1 入力の単位と読み方の判定

REPL では Enter 1 回分、スクリプトでは先頭から順に、1 つずつ入力の単位を読む。

空白とコメントを飛ばした最初の文字が ( なら S式を 1 個読む (複数行にまたがってよい)。

完結した S式は 1 行に複数並べてよい ((cd /tmp) (ls) は 2 つの S式を順に読む)。S式の後ろに bare-line が続くとき ((echo hi) | tr a-z A-Z など) だけ E_PARSE とし、1 つの S式にまとめる書き方を提示する。

行頭が ? と空白 (`? `) のときは AI への質問として扱う。?foo のように空白が続かなければ glob の語で、bare-line として読む。

それ以外は bare-line を 1 行読む。行末の \ は次の行へ続ける。

ファイル先頭の #! の行は無視する。

## 1.2 文字の意味 (S式)

同じ文字でも Lisp の部分とコマンドの語の中で意味が変わるものがあります。語の途中では、特別な意味を持たないのが原則です。

|…|・#・, の読み方は名前の分類 (L2) に依らない。Lisp の部分でもコマンドの語でも、語頭でだけ特別な意味を持つ。

| 文字 | Lisp の部分 | コマンドの語 |
|---|---|---|
| ( ) | リスト | 語の区切り。引数の位置の ( は置換 (L3) |
| " | 文字列 | 文字列。展開しない |
| ' | quote | 語頭のみ: 続く語を展開せずに渡す |
| , ,@ | 語頭のみ: 準クォートの中で値を挿入 | 語頭のみ: 値を挿入。語の途中は文字そのもの (a,b → "a,b") |
| ; | 行末までコメント | 同じ。文字として渡すなら "a;b" |
| #\| \|# | ブロックコメント | 同じ |
| \ | 次の 1 文字をそのまま | 同じ (a\ b → "a b") |
| \| | 語頭のみ: \|Foo Bar\| で大文字小文字と空白を保つ | 語頭のみ。語の途中は文字 (a\|b → "a\|b")。単独の \| \|& はパイプ |
| $ | 語頭でシェル変数の参照 | $ のあとが英字か _ か { なら、語のどこでも変数 (pre$x・${x}.txt)。それ以外は文字 (price$5) |
| # | 語頭のみ: #' #\ #x #( などのディスパッチ | 語頭のみ。語の途中は文字 (a#b)。#. は常にエラー |
| ~ * ? [ ] { } | 記号の一部 | 展開の対象 (L3) |
| < > >> 2> &> など | 比較関数などの記号 (< > はそのまま使える) | 語として単独で現れたらリダイレクト |

(function <) と #'< は Lisp の部分では比較関数として読む。現在は < がリダイレクトと見なされて読み込みエラーになる。

## 1.3 文字列・数・記号

| 種類 | 規則 |
|---|---|
| 文字列 | "…"。エスケープは \n \t \r \e \0 \\ \" \u{1F600}。ほかの \x は x (CL 互換)。改行をそのまま含められる。変数は展開しない |
| 数 (Lisp) | CL の数: 1 1.5 1/2 #x10 1e3 |
| 数 (コマンドの語) | 書いたとおりの文字列 (007 は 007、1.50 は 1.50) |
| 記号 (Lisp) | 大文字に揃える: if・IF・If は同じ、:test は :TEST。\|…\| で囲むと保つ |
| 記号 (コマンド) | コマンド名と語は書いたまま。Git も git も別の語 |
| パッケージ | pkg:name と pkg::name。nshell.user が既定 |
| keyword | :name。Lisp では :NAME、コマンドの語では書いたまま ":name" |

## 1.4 文字の意味 (bare-line)

| 文字 | 意味 |
|---|---|
| ' …' | 展開しない |
| " …" | $var・${var}・$var[i]・$(…) を展開。glob と ~ は展開しない |
| \ | 次の 1 文字をそのまま |
| # | 語頭でコメント。語の途中は文字 |
| \| \|& && \|\| ; & 改行 | 区切り |
| ( … ) | 置換 (L5) |
