# コマンド形式

(NAME ARG …) で、NAME が L2 でコマンドに分類されたもの。引数はすべて文字列の並び (argv) になって渡ります。

## 3.1 引数の書き方と、渡る引数

| 書いたもの | 渡る引数 | 展開 |
|---|---|---|
| foo -n a.txt | 書いたとおり (大文字小文字も) | brace・~・glob |
| "a b" | そのまま 1 個 | なし |
| 'foo | foo | なし |
| 007 1.50 | 書いたとおり | なし |
| :kw | ":kw" (書いたとおり。v0.8 では警告も出す) | なし |
| $xs | 変数の値。リストなら要素ごとに別の引数 | なし (値の中の * は展開しない) |
| $xs[2] $xs[-1] $xs[2..3] | 要素 (1 始まり、負数は末尾から) | なし |
| ${dir}/x pre$x | 連結。値がリストなら要素ごとに連結 (fish と同じ) | なし |
| ,EXPR | 値を 1 個に変換 (3.2) | なし |
| ,@EXPR | リストの各要素を変換して並べる | なし |
| (FORM) | 置換: コマンドなら stdout を行ごとに別の引数 (fish と同じ)。Lisp なら値を変換し、リストは要素ごとに別の引数 | なし |
| $(…) | 中身を bare-line として実行し、stdout を 1 個の引数に (末尾の改行を除く) | なし |
| <(…) >(…) | プロセス置換。パスが渡る | なし |

## 3.2 値から引数への変換

| 値 | 引数 |
|---|---|
| 文字列 | そのまま |
| 整数 | 10 進 |
| 分数・浮動小数 | CL の表記 (1/2 1.5) |
| 文字 | 1 文字 |
| 記号・keyword | 名前。大文字だけなら小文字に (,:verbose → verbose) |
| t | true |
| nil | 引数なし (省略できるフラグに使える: ,(when v "-v")) |
| pathname | パス |
| リスト | , では E_ARG_TYPE (,@ を使う)。( … ) の置換では要素ごと |
| そのほか | E_ARG_TYPE |

## 3.3 展開の順序

記号の語ごとに brace → ~ → 変数 → glob の順。

glob は引用・値・変数の結果には適用しない。

glob が 1 つも一致しなければ E_NO_MATCH (fish と同じ)。文字として渡すなら引用する。v0.8 では警告を出して語のまま渡し、v0.9.0 で E_NO_MATCH にする。

この規則が変えるのはコマンド引数の展開だけで、補完が使う expand-glob は変えない。

## 3.4 リダイレクト

| 演算子 | 意味 |
|---|---|
| > >> 1> | stdout を書き込み・追記 |
| >\| | stdout を書き込み (> と同じ) |
| < 0< | stdin |
| 2> 2>> | stderr |
| &> &>> | stdout と stderr |
| 2>&1 1>&2 >&2 | 記述子の複製 |
| <& | 入力の記述子の複製 |
| <<< | 文字列を stdin に |

<< と <<- (here-doc) は使えない。E_UNSUPPORTED_SYNTAX で拒否し、<<< を使う書き換えを示す (L5.3)。

演算子はコマンド形式の中で独立した語として書いたときだけリダイレクトになる。文字として渡すなら ">" と引用する。

対象は語・文字列・,EXPR・値が 1 つの $var のどれでもよい (現在は ,EXPR が読み込みエラー)。

2>&1 などの複製も他の演算子と同じく扱う (現在は引数として渡ってしまう)。

## 3.5 パイプ・背景・連続

| 形式 | 意味 |
|---|---|
| (\| A B …) | stdout をつなぐ。終了コードは最後の段 (pipefail なら最初の失敗)。$pipestatus に全段 |
| (\|& A B …) | stdout と stderr をつなぐ |
| (& FORM) | 背景のジョブにする。値はジョブ番号 (& を引数の最後に書く形はない) |
| (progn A B) | 順に実行 (bare-line の ;) |
| (and A B) (or A B) | 成功なら次・失敗なら次 (bare-line の && \|\|) |
| (with-env ((FOO "1")) FORM) | その形式の間だけ環境変数を設定 (bare-line の FOO=1 cmd) |

起動できない段の状態は127とし、段ごとに E_COMMAND_NOT_FOUND の診断を stderr へ1回出して入出力のパイプを閉じ（前の段が SIGPIPE で終了してもよい）、残りの段を起動し、$pipestatus に全段の状態を入れ、全体の状態は上表に従い、--json の応答も全体の状態に従う。
