# ロードマップと決定事項

これまでの全ボード (01〜09、U0〜U9、言語仕様 L0〜L7、棚卸し I1〜I10) の提案を 7 つのフェーズに割り当てました。括弧内は出典のボードです。

**順序の理由:** P0 で壊れても戻れる状態を作り、P1 の --json と golden test と適合テストを安全網にしてから、P2 で言語仕様を実装しつつ削ります。言語と構造が固まったあとに、大きい P3 (編集体験と補完の作り直し) と P4 (AI 支援) に入り、P5 で日常使いの品質を詰めます。P3 と P4 は並行できます。

P0

土台

規模 小

AI も人も安心して触れる状態にする

- AGENTS.md と CLAUDE.md (参照のみ) (03)
- test-fast: unit のみ・30 秒以内 (03)
- エラーコード一覧の定義 (02・U6)
- 想定外のエラーからの復帰とクラッシュログ (08)
- --safe で設定なし起動 (08)
- nshell bug-report (08)

P1

機械インターフェースと安全

規模 中

AI が推測せずに使える入口と、同じ規則で動く安全判定

- --json 単発実行と --timeout (02)
- 全メソッド共通の応答の型と出力の節約 (U6)
- initialize・explain・policy・read_output (U5・U6)
- 非対話の既定環境、E_WAITING_FOR_INPUT・E_INTERACTIVE_PROGRAM (U6)
- 危険度判定と効果モデルを Prolog の規則に (06-A・B)
- MCP のツールを拡張 (02)
- --json の golden test と言語仕様の適合テスト (03・L7)

P2

言語の整理と削減

規模 大

golden test を安全網に、言語仕様 v0.8 を実装し、二重実装と計測の層を外す

- 言語仕様 v0.8: 名前解決の順序・置換・値の変換表・capture / status / run・defcmd・スクリプトの先読み (L1〜L6)
- 移行の警告と nshell migrate (L7)
- contracts 層・NFR 計測・競合ベンチを削除 (I9)
- bare-line の制御構文・here-doc・fish 形式の function を警告つきで削除 (I2・L5)
- fish 形式のビルトイン 10 個・prevd / nextd・pipeline-graph (I4)
- slurp / barf・マウス・Ctrl-X 再実行・Alt-C/L/U/T (I5)
- シナリオ 200 件超 → 30〜40 本 (I9)
- cl-dataflow-kit・cl-boundary-kit を外す (04)

P3

編集と表示の体験

規模 大

毎日触る部分を fish 以上の気持ちよさに

- vi モードを fish と同等に: 不足 26 項目・変更 5 項目 (07)
- 補完を DCG と型で作り直す (06-D・E)
- 新しいエラー表示と Alt-Enter の修正適用 (U2)
- AI パネルのキーを 1 組に統一 (U3)
- transient prompt・既定テーマを dracula に・条件つき右プロンプト (U1)
- 非同期プロンプト・あいまい Ctrl-R・頻度順 cd・長時間通知 (U8 すぐ効く)
- 括弧の自動ペアと色分け・対応括弧ハイライト・自動インデント (I5・U8)
- リッチ UI: ブロック表示・インラインの表・ステータスライン・プレビューつき補完・コマンドパレット (U9)

P4

AI 支援

規模 中

人と AI が同じシェルを安全に共有する

- --serve (状態を保つ JSON Lines) (02)
- AI プロバイダ: Claude Code (既定)・Codex・Ollama のアダプタと ai set provider (09)
- ? / Ctrl-] の自然言語入力・ai why・ai explain (03)
- ai why の一次診断を規則で (06-C)
- 承認 ID と --attach の共有セッション、origin = ai (U7)
- (?- …) と MCP の query (06-F)

P5

日常使いの仕上げ

規模 大

壊れない・失わない・どこでも動く、と迷わない

- 履歴の破損回復・schema_version と自動移行 (08)
- 端末・エディタ・ssh の確認表、変わったファイル名と大きな入力 (08)
- fuzz・bash との差分テスト・24 時間 soak・性能予算 6 項目 (08)
- プロジェクト設定と nshell trust・Nix 統合・ユーザー規則の制限 (U8・08)
- nshell init / import・F1・help keys・doctor (U4・06-G)
- 出力ストア・表の自動表示と (view)・clip (U8)
- bash からの書き換え・色覚に配慮したテーマ・スクリーンリーダー向けモード (U8)
- SBOM と artifact attestation (08)

P6

v1.0 判定

規模 小

日常使いの合格基準 7 項目をすべて満たす (08)

- 作者以外 5 人以上・2 週間のログインシェル利用
- クラッシュ時の端末復元と履歴保全を故意のクラッシュで確認
- 確認表・性能予算・fuzz がすべて緑
- nixpkgs と Homebrew での配布
