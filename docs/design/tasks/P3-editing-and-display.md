# P3 編集と表示の体験

規模: 大。P4 と並行できる。`packages/` の再編 (proposal/04 の配置) は P2 の後に行い、P3 はその後に始める。P3 と P4 がともに終わったら v0.9.0 を出し、v0.8 で警告していた変更 (language/L7.2) をそこで切り替える。

## P3-1 vi モードを fish と同等に (proposal/07)

- [ ] 基準は fish 4.9.3 のタグに固定する
- [ ] fish の挙動を「キー列 → 入力欄とカーソル」の表に書き出し、reducer の単体テストにする。表は `t/unit/data/` にデータとして置き、ヘッダに fish のバージョンと SHA を書く
- [ ] tmux で実物の fish を動かして表と照合する CI ジョブ
- [ ] 不足 26 項目と変更 5 項目を実装 (07 の表の「追加」「変更」)
- [ ] 語の区切りは fish と同じにする
- [ ] {vi-mode} セグメント、replace モードの下線カーソル、bind -M、hybrid
- [ ] Esc の待ち時間は 30ms。その間に来た ESC＋文字は vi モード中でも Alt として読む
- [ ] `"*p` はホストの paste コマンドだけを使い、OSC 52 の読み取りはしない
- [ ] Ctrl-N は `bind -M insert` で割り当てる。初期モードは `vi-initial-mode` で設定する
- [ ] Alt-↑ / Alt-↓ は fish と同じにする。入力中はカーソル位置の語で履歴を検索し、入力欄が空のときだけブロック間を移動する

受け入れ条件: 07 の表の全行にテストがある。既存の vi テストも通る。

## P3-2 補完を DCG と型で作り直す (proposal/06 D・E)

- [ ] 手書きカタログと生成 KB を DCG の文法定義に変換
- [ ] 補完の rulebase は P1-5 のものを共用する
- [ ] --help の解析結果も同じ形に。`--help` の実行は今の許可リストとキャッシュのまま
- [ ] 値パイプラインの型 (produces / transforms) と、型に合う次の段だけの補完
- [ ] 既存の補完テストを全部通す。候補の順位が変わるものは理由を記録

## P3-3 エラー表示と修正の適用 (ux/U2)

- [ ] ✗・コード・位置 (^^^)・例・候補の形。--json と同じ情報。L6.2 の新しい見た目の表示はここで作る (エラーを 1 回だけ位置つきで出す処理は P2-1)
- [ ] Alt-Enter で修正候補があれば入力欄へ適用する。候補がなければ P0-9 のとおり改行を入れる。どちらの場合も実行しない

## P3-4 AI パネルの統一 (ux/U3)

- [ ] ? / Ctrl-] / ai why / agent のパネルを 1 つの部品に。キーは Enter・Alt-E・Tab・Esc・Ctrl-C
- [ ] パネルはモーダルにする。パネル内の Alt-E は提案を入力欄へ移し、入力欄での Alt-E は外部エディタのまま
- [ ] パネルの部品は P3-4 が作り、P4-3 はそこへ中身を流す
- [ ] 提案に effects と規則名

## P3-5 表示 (ux/U1・U9)

- [ ] 既定テーマを dracula にし、U1 の色になるように role を付け替える
- [ ] 表示の切り替えは builtin の `ui` で行う (`(ui :rich)` / `:classic` / `:plain`)
- [ ] :rich: ブロック表示 (OSC 133)・ステータスライン・インラインの表・プレビューつき補完・コマンドパレット (Alt-P)
- [ ] ステータスラインは編集中だけプロンプトの下に描く。スクロール領域は使わない
- [ ] レコードの表を描く部品を作る。P5-5 の `(view)` はこの部品を使うページャとして作る
- [ ] 表やステータスラインは cl-tty-kit の上に nshell で作る。文字幅の表を 1 つに保つため、cl-tui-kit は使わない
- [ ] :classic: transient prompt と条件つき右プロンプト
- [ ] 端末の能力の判定と代替 (U9 の表)。起動時の判定は環境変数だけで行う。端末への問い合わせは必要になったときか doctor で行い、TERM=dumb・`--json`・非 TTY では行わない

## P3-6 すぐ効く改善 (ux/U8)

- [ ] 非同期プロンプト
- [ ] あいまい Ctrl-R と絞り込み (この dir・失敗・AI)
- [ ] autosuggest で同じディレクトリの履歴を優先する (cl-history-kit の履歴メタデータを使う)
- [ ] 頻度順の cd。補完の並び順に使うだけで、暗黙のジャンプはしない
- [ ] 長いコマンドの通知。TERM_PROGRAM に応じて OSC 777・9・99 を使い分ける。tmux の下では明示的に有効にしたときだけ出す。閾値は 10 秒
- [ ] 括弧の自動ペアと色分け・対応括弧のハイライト・自動インデント。自動ペアは文字列の中と bare-line では無効。`)` を打ったときは閉じ括弧を飛び越す

## P3-7 実行前の危険表示

- [ ] 入力中に safe・confirm・block の印を出す
- [ ] block のときは Enter を 2 回求める
- [ ] 判定は P1-5 の規則を、入力の区間をキーにしたキャッシュで使う
