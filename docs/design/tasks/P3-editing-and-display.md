# P3 編集と表示の体験

規模: 大。P4 と並行できる。

## P3-1 vi モードを fish と同等に (proposal/07)

- [ ] fish の挙動を「キー列 → 入力欄とカーソル」の表に書き出し、reducer の単体テストにする (fish のソースは 2026-11-11 の main を固定して参照)
- [ ] 不足 26 項目と変更 5 項目を実装 (07 の表の「追加」「変更」)
- [ ] {vi-mode} セグメント、replace モードの下線カーソル、bind -M、hybrid、Esc の待ち時間

受け入れ条件: 07 の表の全行にテストがある。既存の vi テストも通る。

## P3-2 補完を DCG と型で作り直す (proposal/06 D・E)

- [ ] 手書きカタログと生成 KB を DCG の文法定義に変換
- [ ] --help の解析結果も同じ形に
- [ ] 値パイプラインの型 (produces / transforms) と、型に合う次の段だけの補完
- [ ] 既存の補完テストを全部通す。候補の順位が変わるものは理由を記録
