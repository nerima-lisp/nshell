# P6 v1.0 判定

proposal/08 の「日常使いの合格基準」をすべて満たしたら v1.0 を名乗る。このタスクで扱うのは、自動で確かめられる判定だけ。

- [ ] クラッシュしても端末が戻り、履歴が失われない (故意にクラッシュさせるテスト)
- [ ] init.lisp を壊しても --safe で必ず起動できる
- [ ] 端末・tmux・ssh・Emacs の確認表のうち、CI で埋められる行がすべて通る
- [ ] 性能の予算 6 項目を、v0.7.0 の基準に対するラチェットとして守っている
- [ ] パーサと S式リーダーの fuzz で未解決のクラッシュが 0 件
- [ ] bug-report だけで再現に必要な情報が揃う (bug-report の golden test で確かめる)

次は人の作業か計画に入れないものなので、このタスクには含めない。

- 作者以外の 5 人以上が 2 週間ログインシェルとして使い、端末が壊れる・入力できなくなる不具合が 0 件
- nixpkgs と Homebrew への提出と配布
- GUI 端末とスクリーンリーダーでの確認
- 性能の絶対目標値の決定

v1.0 の後: 状況に応じたプロンプトセグメント、複数端末での履歴の同期、次のコマンドの提案、nshell profile。
