# B07: Emacs shell integrations

Prerequisite: Emacs and vterm are installed; configure their shell executable as nshell.

1. Run `M-x shell-command` with `printf B07_COMMAND_OK`.
2. Open vterm, run `printf B07_VTERM_OK`, then exit the shell.
3. Continue using Emacs after each command.

Pass when both markers appear and Emacs retains control of its terminal and buffers.
