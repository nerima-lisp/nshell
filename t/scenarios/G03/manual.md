# G03: Undo and redo

Key notation: `Ctrl-_` means hold Control and type underscore; `Alt-R` means hold Alt or Meta and press R. On macOS, use Option when it is configured as Meta.

1. At an empty prompt, type `echo G03_ORIGINAL`.
2. Press Ctrl-_ repeatedly until the line is empty.
3. Press Alt-R the same number of times, then press Enter.

Pass when the original command is restored and prints `G03_ORIGINAL`.
