# G10: External editor

Prerequisite: set the configured external editor to an editor that saves and exits normally.

1. Type a command but do not execute it.
2. Press `Alt-E` to open the current line in the configured external editor.
3. Change the command, save, and exit the editor.
4. Inspect the returned line and execute it.

Pass when the edited text replaces the prompt buffer and runs once.
